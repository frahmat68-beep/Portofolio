# PANDUAN MENARUH ASSET FOTO & VIDEO PORTOFOLIO

Tinggal drag & drop file foto / video kamu ke folder masing-masing di bawah ini:

---

## 📁 1. Foto Profil & CV (`public/assets/profile/`)
- `avatar.jpg` atau `avatar.png` → Foto profil kamu di Hero / About
- `cv.pdf` → File Curriculum Vitae (CV) kamu

---

## 📁 2. Foto & Video Project (`public/assets/projects/[nama-project]/`)
Di dalam folder ini sudah ada subfolder untuk tiap project:

- `keepsakes/`
- `terimalah-salam-pamitku/`
- `love-in-a-falling-way/`
- `the-claymaker/`
- `jurus-jitu-harra/`
- `reku-relaunch-pack/`
- `bullet-in-a-gun/`
- `dan-hujan-turun/`
- `gula-semut/`
- `tarian-terakhir/`
*(Atau kamu bikin folder baru dengan nama project baru bebas)*

### Format File di dalam folder project:
- **`poster.jpg`** (atau `.png` / `.webp`) → Foto thumbnail / poster utama yang tampil di web
- **`gallery-1.jpg`**, **`gallery-2.jpg`**, dst → Foto-foto stills / adegan tambahan di modal detail
- **`video.mp4`** (opsional) → Video trailer / cutdown kalau ada file mp4 lokal

---

## 📁 3. Foto Behind The Scenes (On-Set) (`public/assets/bts/`)
Taruh semua foto BTS / dokumentasi di lokasi syuting ke sini:
- `bts-1.jpg`, `bts-2.jpg`, `bts-3.jpg`, dst.

---

> **Setelah selesai copy-paste file ke folder:**
> Tinggal bilang ke gue: *"Udah gw taro assetnya, tolong pasangin ke web"* 
> Nanti gue yang langsung scan semua filenya dan update kode portofolio kamu secara otomatis!
